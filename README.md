# Analisis-Pengaruh-Perubahan-Tahun-terhadap-Produksi-Pertanian-di-Indonesia
Ini adalah proyek analisis pengaruh perubahan tahun terhadap produksi pertanian di Indonesia yang kelompok saya buat sebagai proyek tengah semester pada mata kuliah Statistika Multivariat

Hasil analisis ditulis dalam bentuk artikel yang telah terpublikasi di RAGAM: Journal of Statistics and Its Application, yang dapat diakses pada tautan berikut: https://ppjp.ulm.ac.id/journals/index.php/ragam/article/view/14970
